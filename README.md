# 15 ШАГОВ К МИЛЛИОНУ: ФУТБОЛ

Квиз-матч в духе «Кто хочет стать миллионером», но целиком про футбол — и с механикой,
собранной из настоящих футбольных правил: карточки вместо мгновенного вылета, пенальти как
последний шанс, подсказки-замены с окном замен, VAR и банк добавленного времени.

Игра — статический сайт без сборки: `index.html` (HTML + CSS + JS), `questions.js` (база вопросов),
`assets/fonts/` (локальные шрифты). Внешних запросов нет, кроме Яндекс SDK.

## Запуск локально

```bash
cd football
python3 -m http.server 8123
# открыть http://localhost:8123
```

Открывать `index.html` двойным щелчком тоже можно, но через сервер корректнее грузятся шрифты.

## Структура

```
football/
  index.html        вся игра: разметка, стиль, логика
  questions.js      база вопросов + служебные функции выборки и проверки сетки
  DESIGN.md         дизайн-документ: механика, экономика, визуальный язык
  README.md         этот файл
  assets/fonts/     Unbounded (табло) и Nunito (текст), подмножества cyrillic + latin
```

Файл `index.html` разбит на нумерованные секции — и в CSS, и в JS:

| Секция JS | Что внутри |
|---|---|
| 1) КОНСТАНТЫ | лестница призовых, несгораемые зоны, амплуа, реплики комментатора |
| 2) ХРАНИЛИЩЕ И SDK | safeStorage → localStorage → память, Яндекс SDK, реклама, лидерборд |
| 3) ЗВУК | синтезатор на WebAudio: свисток, удар, рёв трибун, карточка |
| 4) СОСТОЯНИЕ | объект матча `S`, рекорды, сейв/загрузка |
| 5) РЕНДЕР | табло, поле-лестница, часы, панель инструментов, хроника |
| 6) ХОД МАТЧА | выбор фланга → вопрос → фиксация → раскрытие → карточки |
| 7) ПОДСКАЗКИ И VAR | окно замен, офсайд / тренер / трибуны, VAR, банк времени, атака |
| 8) КАРТОЧКИ | жёлтая, красная, откат к гарантии |
| 9) ПЕНАЛЬТИ | мини-игра «выбери угол» |
| 10) ИТОГ | подсчёт суммы, статистика, рекорды |
| 11) ОВЕРЛЕИ И МЕНЮ | вспышки, правила, выбор амплуа |
| 12) СТАРТ | привязка обработчиков, клавиатура, инициализация |

## Что настраивать

Всё в `index.html`, секция 1:

- `LADDER` — 15 сумм лестницы (сейчас от 1 000 ₽ до 1 000 000 ₽);
- `SAFE_BASE` — номера несгораемых зон (по умолчанию 5 и 10);
- `TIME_BY_TIER` — секунды на вопрос по сложности 1–5;
- `BANK_STEP` / `BANK_PER_Q` — экономика добавленного времени;
- `POSITIONS` — четыре амплуа и их перки (замены, VAR, банк, множитель суммы, сейвы);
- `SAY` — пулы реплик комментатора по событиям;
- `PEN_SECTORS` (секция 9) — шансы сейва и попадания в каркас по девяти секторам ворот.

Сложность вопроса по номеру шага задаётся в `questions.js` → `TIER_BY_STEP`.

## База вопросов

Живёт в `questions.js`. Сейчас **120 вопросов**: шесть категорий × пять уровней сложности × 4 вопроса.
Этого хватает на полный матч без повторов, но для нормальной переигровки нужно больше —
формат записи, требования к формулировкам и порядок пополнения описаны в шапке самого файла.

Проверить базу: открыть игру и выполнить в консоли браузера

```js
QDB.audit()      // таблица заполненности «категория × сложность», дубли id, битые записи
QDB.audit(10)    // та же проверка с нормой 10 вопросов на ячейку
```

Категория = «направление атаки»: перед каждым шагом игрок выбирает один из трёх флангов,
поэтому на каждую пару «категория × сложность» нужен запас, а не один вопрос.

## Яндекс Игры

- SDK подключается сам, при недоступности игра уходит в автономный режим (без сейвов в облако).
- Обязательный `LoadingAPI.ready()` вызывается после инициализации.
- Прогресс: `safeStorage` → `localStorage` → память. Незаконченный матч восстанавливается
  кнопкой «Продолжить матч» (вопрос при этом переспрашивается заново — перезагрузкой страницы
  нельзя «отменить» неудобный вопрос).
- Реклама: sticky-баннер после готовности, полноэкранная — после итогов матча,
  rewarded — повторный пенальти (один раз за матч).
- Пауза и тишина по `game_api_pause` / `game_api_resume` и по `visibilitychange`.
- Лидерборд: техническое имя **`million`** (сумма за матч). Создать его в Консоли разработчика
  или поменять имя в `submitScore()`.
- Прокрутка, зум, выделение текста и контекстное меню отключены — требование площадки.

Для деплоя заархивировать содержимое папки `football/` (`index.html`, `questions.js`, `assets/`)
и загрузить zip в Консоль разработчика.

## Управление

- Мышь/тап — всё.
- `1`–`3` — выбор фланга атаки.
- `1`–`4`, `A`–`D` (и русские `ФИСВ`) — выбор ответа.
- `Enter` — подтвердить кнопку в открытом окне.
